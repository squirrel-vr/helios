# Launcher backgrounds update instructions:
1. Locate `backgrounds` folder in the repository
2. Put your new images in the folder or delete some of them
3. Commit and push the changes to the repository, run in the root folder: 
    ```
    git add .
    git commit -m "Update launcher backgrounds"
    git push
    ```
---
>Warning: Do not touch or delete the `index.html` file in the `backgrounds` folder, otherwise the launcher will not load backgrounds.
